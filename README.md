# StayNest Hostel Booking — Frontend 

A responsive static HTML/CSS/JavaScript frontend demo. 
## Included
- Responsive explore/home page
- Hostel cards with images, prices, amenities and ratings
- Search by location/name, hostel type and budget
- Quick filters for verified, Wi-Fi, meals and AC
- Save/unsave stays (saved locally in browser `localStorage`)
- Hostel detail modal and demo visit-request button
- Illustrative map panel with clickable price pins
- Mobile bottom navigation
